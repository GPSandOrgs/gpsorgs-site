GPS & Orgs Community site (gpsorgs.com). Static HTML, one shared stylesheet in assets/site.css, no build step. Deployed by Cloudflare Pages from this repo: build command empty, output directory `/`. Pages are generated by `gen.py` (edit the page bodies there, run `python3 gen.py`, commit the HTML).

Pages: index, committee, events, resources, join.

Join form: `functions/api/join.js` stores each signup in the Cloudflare D1 database `gpsorgs-signups` (table `signups`, schema in `schema.sql`). The binding comes from `wrangler.toml`; no secrets and no personal data live in this repo. The working mailing list is the CSV in the community Drive (`GPS Orgs Community/Mailing List/`); pull new signups into it with `sync-mailing-list.py` in that folder.
